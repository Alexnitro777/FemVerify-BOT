# Автокик с голосового канала при роли ЧС

## Ситуация

Файл `src/voiceKick.ts` **уже реализован** и содержит полную логику:
- `kickBlacklistedFromVoice()` — проверяет, есть ли у участника роль ЧС и находится ли он в голосовом канале, и отключает его
- `registerVoiceKick()` — вешает два обработчика:
  - `voiceStateUpdate` — срабатывает при входе/переходе в голосовой канал
  - `guildMemberUpdate` — срабатывает при назначении роли ЧС участнику, который уже в голосовом

**Но модуль НЕ подключён** к `index.ts` — он нигде не импортируется и не вызывается.

Кроме того, **не запрошен intent `GuildVoiceStates`** — без него Discord не шлёт события `voiceStateUpdate`.

## Что нужно сделать

### 1. Добавить intent `GuildVoiceStates` в `src/index.ts`

```ts
// Было:
intents: [
  GatewayIntentBits.Guilds,
  GatewayIntentBits.GuildMembers,
  GatewayIntentBits.GuildInvites,
],

// Стало:
intents: [
  GatewayIntentBits.Guilds,
  GatewayIntentBits.GuildMembers,
  GatewayIntentBits.GuildInvites,
  GatewayIntentBits.GuildVoiceStates,
],
```

### 2. Импортировать и зарегистрировать `registerVoiceKick` в `src/index.ts`

```ts
import { registerVoiceKick } from './voiceKick';
```

И после существующих `register*` вызовов (после `registerInviteTracker(client)`):

```ts
registerVoiceKick(client);
```

## Файлы для изменения

- `src/index.ts` — добавить intent и регистрацию

## Верификация

1. `docker compose up -d --build` — собрать и запустить
2. Назначить участнику роль ЧС (`/выдатьчсп`) когда он в голосовом → должен быть отключён
3. Войти в голосовой канал с ролью ЧС → должен быть отключён при входе
4. Проверить логи: `[voiceKick]` строки при отключении
